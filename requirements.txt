# NHW Data Studio — runtime.
# Anything imported by app/ must be listed here. A missing transitive dep is how
# a Streamlit Community Cloud rebuild takes a working app down weeks after the
# last commit, so the awkward ones are pinned rather than left open.

# Upper bounds on every direct dependency, deliberately. An unpinned major is
# how a deployed app that has not been touched in weeks dies on a rebuild —
# GLIDE went down that way when a transitive starlette release landed. Verified
# working here: streamlit 1.60, altair 6.2, pandas 3.0.5, numpy 2.5, scipy 1.18,
# vl-convert 1.9.
streamlit>=1.40,<2
altair>=5.3,<7

# The typing pass handles both pandas generations: 2.x reads text as object,
# 3.x reads it as StringDtype. Do not narrow this without re-running
# tests/test_pipeline.py — every column role depends on that distinction.
pandas>=2.2
numpy>=1.26
scipy>=1.11            # chi-square for the association findings

# Reading uploads
openpyxl>=3.1          # .xlsx / .xlsm — the fallback reader, and still needed
xlsxwriter>=3.1        # writing the Excel download
# The reader that makes big workbooks bearable. openpyxl parses xlsx as XML in
# Python: one 21-sheet workbook in the archive spent 20 of its 32 seconds in
# there, and a 65,869-row export took 261s against a promise of five minutes.
# calamine reads the same files 6-9x faster with identical results, and opens
# the legacy .xls that openpyxl cannot. Optional by design — profiling.py falls
# back to openpyxl if the import fails, so a failed wheel build is a slowdown
# rather than an outage.
python-calamine>=0.2,<1

# Rendering charts to SVG/PNG for the offline HTML report. Pure-Rust wheel, no
# system dependencies, no browser. Without it the app still runs and the report
# still builds — it falls back to tables and says so on the page.
vl-convert-python>=1.6,<2

# NOT runtime dependencies. The Nigeria boundary files in static/ are vendored
# GeoJSON, read with the standard-library json module. geopandas and shapely are
# needed only to REBUILD them from a source boundary layer:
#   pip install geopandas shapely && python static/build_boundaries.py
# Keeping them out of here is deliberate — they are the heaviest wheels in the
# geo stack and a Streamlit Community Cloud build does not need them to draw a map.

# The "Written brief" page. Listed as a real dependency, not a comment: it was
# optional here on the theory that the tool should work with no API key and no
# account — which is true locally, where you can pip install it later, and wrong
# for a deployment, where you cannot. The key went into the app's secrets and
# the page still reported itself unavailable, because the library that reads the
# key was never installed.
#
# The app still degrades gracefully if it is absent (narrative.available()
# guards the import), so removing this line breaks nothing but the brief.
#
# Major version pinned: app/narrative.py passes `output_config` and `fallbacks`,
# which 0.x releases reject. Nothing it uses was removed in 1.x — no sampling
# parameters, no Text Completions, no raw-response helpers.
anthropic>=1,<2
